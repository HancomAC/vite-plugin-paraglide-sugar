# Security policy

## Supported versions

Security fixes are made for the latest published minor version of
`vite-plugin-paraglide-sugar`. Older versions do not receive fixes; upgrade to the latest
release.

## Reporting a vulnerability

Do not open a public issue, discussion, or pull request for a security problem.

Report it privately through GitHub's private vulnerability reporting: open the
repository's **Security** tab and select **Report a vulnerability**, or go directly to
<https://github.com/HancomAC/vite-plugin-paraglide-sugar/security/advisories/new>.

Include:

- the affected package version, and the Node.js, Vite, Paraglide, and Svelte versions;
- a description of the problem and its impact;
- steps or a minimal project that reproduce it;
- a suggested fix, if you have one.

The maintainers will acknowledge the report, investigate it, and coordinate a fix and its
disclosure with you through the private advisory.
